# Desafio2Excel

O objetivo do exercício era organizar e validar uma planilha de dados cadastrais e informes de rendimentos bancários, garantindo que as informações ficassem certas e fáceis de preencher.

Minha experiência e entendimento:

1.Aba TITULAR:
   - Padronização das informações de cadastro.
   - Aplicação de validação de dados para as opções de "SIM" e "NÃO".
   - Ajuste na formatação visual dos números (como CPF, CEP e telefones).

2.Aba INFORMES:
   - Adição de lista suspensa (menu drop-down) na escolha dos bancos, puxando os nomes direto da aba `TABELAS`.
   - Correção da fórmula de soma do valor total (`=SOMA(...)`) para somar direitinho os saldos.
   - Formatação dos valores como moeda em Reais (`R$`).

3.Aba NOTAS:
   - Criação de validação para selecionar a categoria da entrada (`HOLERITE`, `CNPJ` ou `FREELANCE`).
   - Formatação de valores e organização por data.

4.Aba TABELAS:
   - Lista completa de bancos para servir de apoio e consulta para as outras abas.
